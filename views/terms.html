3. Description of Service

Cassie is a multipurpose Discord bot providing moderation, utility, entertainment, economy, and AI-powered features. The Bot also provides a web dashboard for server management via Discord OAuth authentication. The Bot runs on infrastructure operated by the developer; no hosting providers or cloud services are used for data processing or storage.

4. Features

The Bot provides the following categories of features. Server administrators control which features are enabled in their server.

  • Moderation — Ban, kick, timeout, warn, jail, image mute, reaction mute, purge, channel lock, role management, and moderation case logging.
  • Auto-Moderation — Configurable filters for spam, mass mentions, NSFW, malicious links, excessive caps/emoji, and custom regex patterns. Includes a strike escalation system.
  • Anti-Nuke & Anti-Raid — Protection against compromised accounts performing destructive actions (mass bans, channel/role deletion) and mass-join raids.
  • AI Chat — Conversational AI powered by a locally-hosted language model (Ollama, running on the developer's own hardware). The AI has access to tools including web search, calculator, server data lookups, and read-only database queries. The AI maintains per-user persistent memory.
  • Economy — Virtual currency system with daily claims, work commands, leaderboards, and peer-to-peer transfers. Each server has its own independent economy.
  • Gambling — Slot machine, blackjack, and coinflip games using virtual currency. See Section 5 for important disclaimers.
  • Levels & XP — Activity-based leveling from messages and voice time, with role rewards and milestones.
  • Tags — User-created text snippets retrievable by command.
  • Reminders & To-Do Lists — Personal reminder and task management.
  • Starboard — Community-curated message pinning based on reaction counts.
  • VoiceMaster — Temporary voice channels created on-demand.
  • Tickets — Support ticket system with forms, claiming, and transcripts.
  • Invite Tracking — Track who invited whom, detect fake/alt accounts.
  • Reaction Roles — Self-assign roles via message reactions.
  • Echo Chamber — Anonymous delayed-message relay channels.
  • Boost Notifications — Auto-thank users for server boosts.
  • Court System — Community voting on playful "court cases."
  • Action GIFs — ~140 animated reaction GIF commands (hug, slap, etc.).
  • Utility — Ping, stats, time/timezone, dice roller, 8-ball, and other small tools.

5. Virtual Currency & Gambling

The Bot includes an economy and gambling system that uses a virtual currency ("Cass Bits"). Important disclaimers:

  • The virtual currency has no real-world value and cannot be purchased, sold, exchanged for real money, or transferred between servers.
  • Each server maintains its own independent economy. Currency earned in one server cannot be used in another.
  • Server administrators can disable the economy and gambling features entirely.
  • The gambling games (slots, blackjack, coinflip) are randomized and use virtual currency only. They are not real-money gambling.
  • You are responsible for configuring appropriate gambling limits in your server.

6. AI Features

The Bot includes AI-powered conversational features. By using the AI chat, you understand and agree that:

  • The AI model runs locally on the developer's hardware. Your messages are processed locally and are not sent to third-party cloud AI services.
  • The AI has access to read-only tools that can query the Bot's database. User-scoped data (your todos, reminders, economy balance, chat history) is only accessible to you. The AI cannot access moderation configs, sessions, or other users' private data.
  • The AI maintains a persistent memory per user (~1000 words) that it can read and write during conversations. You can request deletion of your AI memory at any time.
  • Chat history is stored to provide conversational context. You can request deletion of your chat history at any time.
  • The AI's web search tool sends search queries to the LangSearch API (api.langsearch.com). Only the search query is transmitted; no personal data is attached.
  • The AI is a language model and may produce inaccurate, incomplete, or misleading information. Do not rely on the AI for medical, legal, financial, or safety-critical decisions.
